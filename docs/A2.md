`src/core/EventBus.ts` 是这个项目的**全局消息中心**。它基于 PlayCanvas 的 `EventHandler` 封装了一个单例模式，用于让不同的系统（如 UI、敌人、玩家、游戏逻辑）之间进行**解耦通信**。

简单来说，就是“**A 发生了一件事，告诉 EventBus，EventBus 通知所有关心这件事的 B、C、D**”，而 A 不需要知道 B、C、D 的存在。

以下是具体的用法指南，结合了你项目中的实际代码：

### 1. 获取 EventBus 实例

由于它是单例，你在任何地方都通过 `getInstance()` 获取同一个实例。

```typescript
import { EventBus } from "../core/EventBus"; // 根据文件位置调整路径

// 在类的方法中
const bus = EventBus.getInstance();
```

### 2. 触发事件 (Fire)

当你希望通知其他系统发生了某事时使用。你可以传递任意数量的参数。

**场景举例**：比如在 `BulletBehavior.ts` 中，子弹击中敌人时：

```typescript
// 触发 'combat:hit' 事件，并传递 3 个参数：目标实体、伤害值、击中位置
EventBus.getInstance().fire("combat:hit", this.target, 10, hitPosition);
```

### 3. 监听事件 (On)

当你希望在某事发生时执行代码时使用。通常在 `initialize()` 或构造函数中绑定。

**场景举例**：比如在 `HUD.ts` (UI) 中，需要监听血量变化来更新血条：

```typescript
export class HUD {
  private eventBus: EventBus;

  constructor() {
    this.eventBus = EventBus.getInstance();

    // 语法: .on(事件名, 回调函数, 作用域context)
    this.eventBus.on("ui:updateHealth", this.onUpdateHealth, this);
  }

  // 回调函数接收 fire 传递过来的参数
  private onUpdateHealth(current: number, max: number) {
    console.log(`血量更新: ${current}/${max}`);
    // 更新 UI 逻辑...
  }
}
```

### 4. 取消监听 (Off) - **非常重要**

为了防止内存泄漏或报错，当一个对象被销毁（`destroy`）时，**必须**取消它注册的所有事件。

```typescript
// 在类的 destroy 方法中
public destroy() {
    // 参数必须与 on 的时候完全一致
    this.eventBus.off('ui:updateHealth', this.onUpdateHealth, this);
}
```

### 5. 监听一次 (Once)

如果你只关心事件的**第一次**触发（比如“游戏初始化完成”），使用 `once`。触发一次后会自动取消监听。

```typescript
this.eventBus.once(
  "game:loaded",
  () => {
    console.log("游戏加载完毕，只打印一次");
  },
  this
);
```

### 项目中现有的常用事件一览

你在开发新功能时，可以复用这些事件或模仿它们的命名规范：

| 事件名            | 参数                   | 触发时机            | 监听者 (举例)                 |
| :---------------- | :--------------------- | :------------------ | :---------------------------- |
| `ui:updateHealth` | `current, max, shield` | 玩家血量变化时      | `HUD` (更新血条)              |
| `ui:updateExp`    | `current, max, level`  | 玩家经验/等级变化时 | `HUD` (更新经验条)            |
| `combat:hit`      | `target, damage, pos`  | 子弹/攻击击中目标时 | `CharacterSystem` (飘字/特效) |
| `combat:damage`   | `damage, pos, color`   | 敌人/玩家实际扣血时 | `EnemySystem`                 |
| `enemy:death`     | `pos, expValue`        | 敌人死亡时          | `EnemySystem` (生成掉落物)    |
| `player:gainExp`  | `amount`               | 捡到经验球时        | `CharacterSystem` (增加经验)  |
| `game:over`       | 无                     | 玩家死亡时          | `GameManager` (结束游戏)      |

### 最佳实践建议

1.  **作用域 (Scope)**：调用 `on` 时，第三个参数通常传 `this`，这样在回调函数里才能访问类的成员变量。
2.  **命名规范**：建议使用 `类别:动作` 的格式（如 `player:jump`, `ui:show`），这样代码更易读。
3.  **参数类型**：虽然 EventBus 允许传 `any`，但在写回调函数时，最好明确参数类型以便于维护。
