下面把《吸血鬼幸存者》及其同类（“类吸血鬼”）游戏常见的三大系统——“玩家数值”“增益卡”“武器卡”——拆成设计清单，方便你直接拿去拼装或二次创作。所有条目均来自现有产品拆解与源码分析，已去掉具体 IP 名称，可放心做换皮或玩法迭代。

一、可为玩家维护的 20+ 核心数值  
（= 角色面板里真正存进 save 文件、会被卡牌或武器实时读写的变量）

1. 生命/护盾类
   - 当前生命、最大生命、临时护盾、护盾上限、吸血转化率、生命再生/秒、击杀回血、拾取回血
2. 攻击类
   - 基础伤害、伤害倍率、暴击率、暴击倍率、攻击速度（CD 缩减）、弹道数量、穿透次数、溅射范围
3. 防御/生存类
   - 护甲、伤害减免%、闪避率、移动速度、碰撞伤害反伤、复活次数、复活后无敌时间
4. 资源/经济类
   - 经验获取倍率、金币倍率、商店折扣、宝箱品质、幸运值（影响 roll 卡与掉落）
5. 机制类
   - 冷却缩减上限、技能持续时间、投射物尺寸、拾取范围、诅咒层数（敌人变强但经验多）、连击计数器、Rage 怒气条

二、可做的 30 张“增益卡”模板  
（= 每局随机 roll 的被动 Buff，可叠加、可升星、可与武器联动）

1. 数值线性放大
   - 力量+10% 伤害、狂怒+15% 攻速、铁壁+8 护甲、步风+10% 移速、贪婪+20% 金币
2. 机制质变
   - 双重射击：弹道+1；穿透专家：穿透+2；暴击狂热：暴击率叠层；吸血光环：2% 伤害转生命
3. 经济/roll 卡
   - 幸运草：幸运+30；商人朋友：商店刷新-1 金；宝箱猎人：宝箱掉率+15%
4. 风险-收益
   - 诅咒契约：敌人生命+50%，但经验+60%；玻璃大炮：伤害+25%，生命-15%；破釜沉舟：生命低于 30% 时攻速+40%
5. 联动专用
   - 空心之心：最大生命+20%，且是“血鞭”武器的必要合成材料；烛台：范围+25%，是“镰刀”合成材料；空书：冷却-8%，是“圣魔杖”合成材料
6. 特殊规则
   - 磁石：拾取范围+50%；香蕉：满血时掉落的鸡腿自动变成炸弹；奥术骰子：每 60s 随机重置一张卡牌等级

三、可做的 40 张“武器卡”模板  
（= 主动或自动发射的主力技能，可单独升级、可合成“超武”）

1. 近程
   - 鞭影：左右横扫，可吸血；镰刀：高抛物线，进化后 360° 旋转；拳套：短程震荡波，带击退
2. 直射
   - 魔杖：自动锁定最近敌人；飞刀：高速直线，带轻微击退；圣枪：激光直线穿透，可暴击
3. 范围溅射
   - 圣经：环绕本体旋转，进化后转速翻倍；火球：随机目标小范围爆炸；圣水：地面持续灼烧；十字炸弹：投掷后延时十字型爆炸
4. 召唤/连锁
   - 闪电戒：连锁 3 敌人；冰龙：召唤幼龙自动喷冰；暗影分身：复制自身 30% 伤害的影子
5. 超武合成示例（给出公式即可）
   - 血鞭 = 鞭子 + 空心之心（吸血+范围延长）
   - 千刃 = 飞刀 + 护腕（移除发射 CD）
   - 地狱火 = 火魔杖 + 菠菜（火球变大且穿透）
   - 死亡旋风 = 斧头 + 烛台（360° 镰刀）
   - 天堂之剑 = 十字架 + 四叶草（回旋大剑）
   - 雷环 = 闪电戒 + 复制器（双重闪电）
   - 破坏者 = 和平鸽 + 乌木之翼（全屏清怪）

设计小贴士

1. 每把武器最多 8 级，超武合成后再开 8 级，玩家就有“两段成长”爽点。
2. 增益卡尽量用“乘法区间”而不是简单加法，可防止数值爆炸。
3. 给每张武器卡预设“标签”（火/冰/雷/暗/圣/物理），方便后续做敌人弱点、专属 Buff、成就系统。
4. 留 2-3 个“废卡”或“整蛊卡”——比如“香蕉皮”移速-5%，玩家 roll 到后会笑出声，反而增加直播效果。

把上面清单丢进 Excel，横向拉一拉星级系数、纵向配一配合成公式，就能在 1-2 周内拼出一款可玩的“类吸血鬼”原型。祝开发顺利！
